Glosario

Explora los términos clave, acrónimos y definiciones relacionadas con la administración de bases de datos.

A Términos con A

Administrador de Base de Datos (DBA):
Profesional responsable de la instalación, configuración, seguridad, monitoreo y mantenimiento de los sistemas de bases de datos de una organización.

Atributo:
Cada una de las propiedades o características que definen a una entidad en el modelo relacional (corresponde a las columnas de una tabla).

B Términos con B

Backup (Respaldo):
Copia de seguridad de los datos que permite restaurar la información en caso de pérdida, corrupción o falla del sistema. Puede ser en frío (base de datos apagada) o en caliente (en ejecución).

C Términos con C

Commit:
Instrucción del Lenguaje de Control de Transacciones (TCL) que guarda de forma permanente todos los cambios realizados durante la transacción actual.

Concurrencia:
Capacidad de un Sistema Gestor de Bases de Datos para permitir que múltiples usuarios accedan y modifiquen los datos simultáneamente sin perder la integridad de la información.

D Términos con D

DDL (Data Definition Language):
Subconjunto de SQL utilizado para definir o modificar la estructura de los objetos en la base de datos (Ej. CREATE, ALTER, DROP).

DML (Data Manipulation Language):
Subconjunto de SQL utilizado para gestionar los datos dentro de las estructuras (Ej. SELECT, INSERT, UPDATE, DELETE).

S Términos con S

SMBDR:
Sistema Manejador de Bases de Datos Relacionales. Software que permite la creación, gestión y administración de bases de datos basadas en el modelo relacional.

SQL (Structured Query Language):
Lenguaje de programación estándar e interactivo para la obtención de información y administración de bases de datos relacionales.
