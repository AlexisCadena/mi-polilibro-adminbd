Unidad I. Operaciones básicas de los SMBDR

En esta unidad comprenderemos cómo interactúan los usuarios, los datos y el hardware mediante el Sistema Gestor de Base de Datos...

1.1 Funciones de SMBDR

Un Sistema Manejador de Bases de Datos Relacionales (SMBDR) tiene como funciones principales:


  • Abstracción de la información.
  • Independencia de los datos.
  • Redundancia mínima.
  • Seguridad y control de acceso.

1.2 Modelo relacional y las 12 reglas de Codd

El modelo relacional fue propuesto por Edgar F. Codd en 1970. Para que un sistema sea considerado un verdadero sistema de gestión de bases de datos relacionales, debe cumplir con 12 reglas (enumeradas del 0 al 12), entre las cuales destacan:


  • Regla 1 (Regla de la información): Toda la información debe estar representada explícitamente a nivel lógico en forma de tablas.
  • Regla 2 (Acceso garantizado): Todos los datos deben ser accesibles sin ambigüedad.
  • Regla 3 (Tratamiento sistemático de valores nulos): El sistema debe soportar una representación para la información faltante.

1.3 Componentes y ambiente de trabajo

El entorno de un gestor de base de datos suele basarse en una arquitectura Cliente/Servidor. Sus componentes principales incluyen:


  • Motor de la Base de Datos: Procesa las peticiones.
  • Procesador de Consultas: Traduce el código SQL a instrucciones de bajo nivel.
  • Gestor de Transacciones: Garantiza las propiedades ACID (Atomicidad, Consistencia, Aislamiento y Durabilidad).

1.4 Estructura de almacenamiento y objetos

Las bases de datos organizan la información tanto lógica como físicamente. Los objetos lógicos más comunes son:


  • Tablas: Entidades compuestas por filas y columnas.
  • Vistas: Consultas almacenadas que actúan como tablas virtuales.
  • Índices: Estructuras para acelerar la recuperación de datos.
  • Procedimientos Almacenados: Bloques de código ejecutables en el servidor.

1.5 Instrucciones estándar de lenguaje estructurado de consulta (SQL)

El lenguaje SQL se divide en varios sublenguajes dependiendo de la acción que se desea realizar:


  • DDL (Data Definition Language): CREATE, ALTER, DROP.
  • DML (Data Manipulation Language): SELECT, INSERT, UPDATE, DELETE.
  • DCL (Data Control Language): GRANT, REVOKE.
  • TCL (Transaction Control Language): COMMIT, ROLLBACK.
