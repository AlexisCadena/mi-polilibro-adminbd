Bienvenido al Polilibro

Este material interactivo está diseñado para guiarte en el dominio de la Administración de Bases de Datos. A lo largo de este curso, desarrollarás las competencias necesarias para instalar, configurar, asegurar y optimizar Sistemas Gestores de Bases de Datos (SGBD) en entornos empresariales.


Objetivo General

Administrar, mantener y optimizar bases de datos garantizando la integridad, disponibilidad y seguridad de la información, utilizando herramientas de monitoreo y sentencias avanzadas para la toma de decisiones.

Contenido Temático

Unidad I. Operaciones básicas de los Sistemas Manejadores de Bases de Datos. Relaciones (SMBDR)

Usa instrucciones de operaciones de manejo de información con base en el SQL como lenguaje estándar de los SMBDR.

  • Funciones de SMBDR.
  • Modelo relacional y las 12 reglas de Codd.
  • Componentes y ambiente de trabajo.
  • Estructura de almacenamiento y objetos.
  • Instrucciones estándar de lenguaje estructurado de consulta (*Structured Query Language/SQL).

Unidad II. Instrucciones de Administración de Bases de Datos Relacionales

Emplea instrucciones de Administración de Bases de Datos Relacionales.

  • Consultas simples y multitabla.
  • Administración de la seguridad e integridad de la información en un Sistema Manejador de Bases de Datos Relacionales (SMBDR).
  • Control de concurrencia y técnicas de bloquo.
  • Implementación de transacciones, procedimientos, almacenados, disparadores, funciones y cursores.
  • Respaldos y recuperación de las Bases de Datos Relacionales.

Unidad III. Herramientas y asistentes de un Sistema Manejador de Bases de Datos Relacionales (SMBDR)

Utiliza herramientas y asistentes de administración automatizada a partir de los alcances de los SMBDR.

  • Herramienta para crear y administrar la estructura de Base de Datos Relacionales.
  • Herramienta para crear y administrar usuarios y privilegios.
  • Herramienta para crear y administrar respaldos, dispositivos de recuperación y archivos bitácora.
  • Herramientas para administrar y configurar.
  • Utilerías de mantenimiento y asistentes de tareas administrativas.
